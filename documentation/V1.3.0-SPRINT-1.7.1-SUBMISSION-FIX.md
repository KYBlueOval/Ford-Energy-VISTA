# VISTA v1.3.0 Sprint 1.7.1

## Registration submission fix

The public registration portal now submits through a hidden HTML form and Apps Script iframe response bridge. This avoids browser CORS restrictions while preserving a verified success/error response.

## Notifications

After the visit record and photo are saved, Apps Script sends:

- Sponsor action/request email to the selected SponsorEmail
- Visitor confirmation email
- Optional Security notification to the Config `NOTIFICATION_EMAIL` value

Email failure does not discard an otherwise successful registration. Notification status is returned to the confirmation screen.

## Deployment

1. Replace the GitHub repository files and push through GitHub Desktop.
2. Replace Apps Script `Code.gs` with `apps-script/Code.gs`.
3. Save and deploy a new Web App version using the existing deployment.
4. Confirm Execute as: Me and Who has access: Anyone.
5. Test a complete registration.
