# VISTA Sprint 1.8.0

## Included
- Visitor lifecycle colors: Submitted gray, Approved yellow, Checked In blue, Checked Out green, Denied/Rejected red, No Show orange.
- Status row accent colors and synchronized detail status.
- Reliable photo detection using PhotoFileId, PhotoFileName, or PhotoUrl.
- Photo download defaults to `Visitor Full Name-Company.jpg/png/webp`.
- Future-safe object-to-header row writing so worksheet column order cannot corrupt new records.
- `repairVisitRequestsHeaders()` creates a backup and restores the canonical VisitRequests header row.

## Required Apps Script step
After replacing Code.gs and deploying a new version, run `repairVisitRequestsHeaders()` once from the Apps Script editor. Authorize it when prompted. Verify the backup sheet exists before testing a new registration.

## Sponsor protection
This package does not contain `public-registration/data/sponsors.json`. The GitHub Action remains its only owner.
