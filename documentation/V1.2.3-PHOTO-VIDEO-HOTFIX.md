# VISTA v1.2.3 Photo and Training Video Hotfix

## Changes

- Sponsor email remains searchable and selectable from the `Sponsors` sheet, while still allowing an unlisted email to be typed manually.
- `Remove Background` now uses MediaPipe person segmentation instead of the prior edge-color replacement method. The isolated visitor is composited over a solid light-blue background.
- Training video URLs now support:
  - YouTube watch, short, and embed URLs
  - Google Drive share URLs using the Drive preview player
  - Direct browser-playable MP4/WebM URLs
  - A fallback link when the browser cannot play the embedded file

## Deployment

1. Upload the v1.2.3 GitHub files over the current repository.
2. Replace Apps Script `Code.gs` with the v1.2.3 file.
3. Run `setupVisitorManagement()` once.
4. Deploy a new Apps Script Web App version.
5. Hard-refresh the registration page with Ctrl+F5.

## Training video configuration

Set `TRAINING_VIDEO_URL` in `public-registration/config.js`. A Google Drive share link such as `https://drive.google.com/file/d/FILE_ID/view` is now automatically converted to the Drive preview player. The file must be shared so intended visitors can view it.

## Background-removal dependency

Background removal loads the MediaPipe Selfie Segmentation model from jsDelivr. The visitor device must have internet access to that CDN. If the model is blocked, the original cropped photo is retained and the user is informed.
