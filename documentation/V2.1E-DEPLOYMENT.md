# VISTA 2.1E Deployment and Test Guide

## Scope
This frontend-only sprint adds role-based avatar border colors. No Apps Script deployment or spreadsheet schema change is required.

## Color rules
- Visitor: neutral gray
- Security and Front Desk: Ford blue
- Security Supervisor: bright blue
- Admin and Super Administrator: green
- Sponsor: orange (reserved)
- Approver: purple (reserved)
- Unknown/read-only roles: slate gray

## Deploy
1. Upload the complete repository to GitHub.
2. Wait for GitHub Pages deployment to finish.
3. Hard-refresh Administration and Security Operations with Ctrl+F5.
4. Confirm each module footer displays Version 2.1E.

## Tests
1. Sign into Security Operations as a Super Administrator or Admin and confirm the header photo has a green border.
2. Sign in as Security or FrontDesk and confirm the header photo has a Ford-blue border.
3. Sign in as Security Supervisor and confirm the header photo has a brighter blue border.
4. Open Administration and confirm each user-row avatar border follows the user role.
5. Open Security Operations and confirm every visitor thumbnail uses the same neutral gray border regardless of reservation status.
6. Confirm users and visitors without photos retain initials/placeholders with the same role/type border color.
