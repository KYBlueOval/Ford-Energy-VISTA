# VISTA Sprint 1.9 — Identity and Role-Based Access

Run `setupVistaIdentityAndRoles()` once in Apps Script. It creates/updates: `Users`, `FrontDesk`, `Security`, `AuthSessions`, and `AuditLog`.

Initial account: `vistaadmin`; its PIN is the current `SECURITY_PIN` in Config. Immediately run `setVistaUserPin("vistaadmin","NEW_PIN")`.

Roles: Sponsor/Approver, FrontDesk, Security, Admin. Badge assignment and check-in are enforced on both the interface and backend and require visit status `Approved`.

To add staff, populate FrontDesk or Security, run `syncVistaRoleRosters()`, then run `setVistaUserPin("username","PIN")`. Create sponsors/approvers with `createVistaUser(employeeId, fullName, email, "Sponsor", pin, department, company, badgeUID)`. Their email must match the SponsorEmail on assigned visits.
