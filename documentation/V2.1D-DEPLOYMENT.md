# VISTA 2.1D Deployment and Test Guide

## Scope
This frontend sprint adds lazy-loaded authenticated thumbnails to Administration user rows and Security Operations visitor rows. No Apps Script schema or Config changes are required beyond the existing 2.1C backend.

## Deploy
1. Upload the complete repository to GitHub.
2. Wait for GitHub Pages deployment to finish.
3. Hard-refresh Administration and Security Operations with `Ctrl+F5`.
4. Keep the existing Apps Script deployment and `USER_PHOTO_FOLDER_ID` configuration.

## Test
1. Sign into Administration and confirm users with saved profile photos show circular photographs; users without photos retain initials.
2. Sign into Security Operations and confirm visitor rows progressively load circular thumbnails.
3. Open a visitor and confirm the larger record photo still loads and can be downloaded.
4. Refresh or reopen records during the same browser session and confirm already-loaded images appear without another visible loading delay.
5. Confirm missing or inaccessible images fall back safely without blocking the dashboard.

## Performance behavior
Visitor photos are retrieved through the authenticated Apps Script endpoint with no public Drive exposure. Requests are de-duplicated, cached for the current page session, and limited to four concurrent thumbnail loads.
