# VISTA 2.2.2A Deployment and Test Guide

## Scope
This incremental build focuses on workflow stability and the operational refinements reported during 2.2.1 testing.

## Deployment
1. Replace Apps Script `Code.gs` with the included file.
2. Save and deploy a new web-app version while retaining the current URL.
3. Upload the complete repository to GitHub Pages.
4. Hard refresh Administration and Security Operations with `Ctrl + F5`.

No sheet schema change and no setup function run are required.

## Badge number setup
The Security Operations panel reads `BadgeNumber` from the existing `BadgeInventory` sheet by matching `BadgeUID`.
Example:
- BadgeUID: `1234213-T1`
- BadgeNumber: `0017`

The panel will display `Visitor Badge 0017 | 1234213-T1`. If BadgeNumber is blank, the UID remains visible by itself.

## Regression tests
1. Open Edit User and close it with X, Cancel, Escape, and backdrop click.
2. Edit a user photo and verify the Save button shows progress and the dialog closes after success.
3. Edit the currently signed-in administrator and verify the session remains active.
4. Check in an approved visitor; verify the completion dialog counts down from 12 seconds and can be closed immediately.
5. Verify a checked-in visitor displays both physical badge number and UID when BadgeInventory contains the mapping.
6. Check the root, registration, administration, and security footers for the centered BWRDO mark.
