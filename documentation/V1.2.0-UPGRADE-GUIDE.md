# Ford Energy VISTA v1.2.0 Upgrade Guide

## 1. Back up production
Download the current Google Sheet as XLSX and retain the current GitHub release ZIP.

## 2. Update Apps Script
Replace `Code.gs` with the v1.2.0 file, save, and run `setupVisitorManagement()` once from the Apps Script editor. Authorize access when prompted.

The setup adds or updates these sheets without deleting existing rows:
- VisitRequests
- VisitActivity
- BadgeInventory
- Agreements
- AgreementAcknowledgements
- Config

## 3. Update Config
Set these keys in the Config sheet:
- PHOTO_FOLDER_ID
- NOTIFICATION_EMAIL
- SECURITY_CONSOLE_URL
- PUBLIC_REGISTRATION_URL
- VGS_NAVIGATION_URL
- TRAINING_VIDEO_URL
- AGREEMENT_VERSION
- ARRIVAL_INSTRUCTIONS
- PARKING_INSTRUCTIONS

`TRAINING_VIDEO_URL` may be a direct MP4 URL or a YouTube URL. For sensitive internal content, use an approved hosting method that visitors can access without exposing restricted material.

## 4. Redeploy Apps Script
Deploy > Manage deployments > Edit > New version > Deploy. Keep **Execute as: Me** and the same access configuration already used by the working deployment.

## 5. Update GitHub Pages
Copy the contents of `FordEnergy-VisitorManagement` into the repository root, commit, and push. Verify:
- `/`
- `/public-registration/`
- `/security-console/`

## 6. Production test
Submit one test visitor and confirm:
- photo stored in the configured Drive folder
- VisitRequests row created
- seven AgreementAcknowledgements rows created
- agreement content hashes populated
- visitor confirmation email delivered
- sponsor/security email delivered
- visitor appears in the Security Console
- photo loads from the Security Console
- Approve, Check In, and Check Out remain functional
