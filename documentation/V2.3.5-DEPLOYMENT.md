# VISTA 2.3.5 — Operational Analytics Foundation

## Deployment

1. Replace the Apps Script `Code.gs` with `apps-script/Code.gs` from this release.
2. Save the Apps Script project.
3. Create a new web-app deployment version and retain the existing web-app URL.
4. Deploy the repository contents to GitHub Pages.
5. Hard-refresh Administration with `Ctrl + F5`.

No spreadsheet migration or `setupVista()` run is required for this release. Existing Config values, Drive folder IDs, roster worksheets, and operational records remain unchanged.

## Test sequence

1. Sign in to Administration as Admin or Super Administrator.
2. Confirm `VISTA Analytics` appears below the Administration hero.
3. Verify the default 30-day reporting range loads.
4. Compare Visits, Currently Onsite, and badge totals against the spreadsheet records.
5. Change the reporting period to 7, 90, and 365 days and confirm metrics and charts refresh.
6. Confirm Visit Outcomes includes Submitted, Approved, Checked In, Checked Out, Denied, and No Show.
7. Confirm Daily Visit Volume and Top Sponsors render without horizontal overflow.
8. Confirm Badge & Handoff Health reflects BadgeInventory and ShiftHandoffs.
9. Confirm average acknowledgement and resolution times update after completing handoff workflows.
10. Confirm a non-authorized API session cannot call `getOperationalAnalytics`.

## Regression checks

- Administration user and badge management remain operational.
- Security Operations approval, check-in, checkout, photos, handoffs, and escalation remain operational.
- Public visitor registration and sponsor synchronization remain unchanged.
- No external charting or analytics provider receives VISTA data.
