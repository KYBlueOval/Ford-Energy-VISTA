# VISTA v1.3.0 Sprint 1.8a

## Ford Energy favicon and browser branding

This release applies Ford Energy browser branding to:

- the VISTA landing page
- Visitor Pre-Arrival Registration
- the Security Operations Console

## Added files

- `favicon.ico`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `apple-touch-icon.png`
- `favicon-192.png`
- `favicon-512.png`
- `site.webmanifest`
- matching copies under `shared/assets/branding/`

## Deployment

Copy the root-ready package into the local GitHub Desktop repository, commit, and push. After GitHub Pages deploys, use a hard refresh. Browsers can cache favicons aggressively; closing and reopening the tab may also be required.

## Sponsor directory protection

The release package intentionally excludes `public-registration/data/sponsors.json`. That generated file remains owned by the `Sync VISTA Sponsors` GitHub Action.
