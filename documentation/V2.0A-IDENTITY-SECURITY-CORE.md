# VISTA 2.0A — Identity & Security Core

Delivered:
- Badge-first Security Console login
- PIN fallback
- Multiple badge UID support using colon, semicolon, comma, pipe, or line breaks
- Duplicate badge assignment rejection
- PIN failure lockout
- Absolute and idle session expiration
- Role-aware permissions enforced by Apps Script
- Public sponsor directory stripped of saved email addresses
- Private server-side sponsor email resolution

After replacing Code.gs and deploying a new web-app version, run:

`applyVista20ASecurityDefaults`

Then run the `Sync VISTA Sponsors` GitHub Action and verify the public sponsors.json contains no email field.
