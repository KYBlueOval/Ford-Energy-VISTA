# VISTA 2.7.1 — Native Android Experience and NFC Authentication

VISTA 2.7.1 replaces the prototype WebView launcher with a native Ford Energy mobile operations shell and native secure sign-in.

## Native experience

- Production Ford Energy brand asset and updated application icon
- Dimensional VISTA hero, status panel, workspace cards, and public-service cards
- Native Security Operations, Sponsor & Approver, and Administration entry controls
- Native badge and PIN sign-in before a protected workspace is opened
- Role permission validation for the selected workspace
- Secure session transfer into the selected VISTA web workspace

## NFC correction

The previous client depended on `enableForegroundDispatch`, which did not reliably discover the ISO/IEC 14443-4 and DESFire-compatible employee credentials used at the site. Version 2.7.1 uses the BadgeValidator acquisition model:

- `NfcAdapter.enableReaderMode` is the primary path.
- NFC-A and NFC-B are enabled.
- `FLAG_READER_SKIP_NDEF_CHECK` prevents Android from treating a secure badge as a conventional NDEF tag.
- Foreground dispatch and NFC launch intents remain as fallbacks.
- Badge UIDs are normalized as uppercase hexadecimal without separators.
- A 900 ms duplicate window prevents a single badge presentation from being processed twice.

## Physical-device acceptance test

1. Install the 2.7.1 debug APK on the intended NFC-capable Android device.
2. Select Security Operations and tap an authorized VISTA employee badge.
3. Confirm the native screen shows the UID and opens the authorized Security workspace.
4. Return home, select Sponsor or Administration, and confirm role restrictions are enforced.
5. Within Security Operations, open visitor badge assignment and scan a visitor badge.
6. Verify the UID reaches the active field and completes the normal VISTA server workflow.
7. Verify camera capture for manual visitor intake, incidents, and handoffs.

The Android emulator validates layout, build, and navigation but cannot prove physical NFC antenna or badge technology behavior.
