# VISTA v1.3.0 Sprint 1.1 Sponsor Lookup Hotfix

This release fixes the saved sponsor picker returning no matches even when active sponsor rows exist.

## Deployment
1. Replace the Apps Script `Code.gs`.
2. Save and deploy a **new web app version**.
3. Upload the GitHub project files.
4. Hard refresh the public registration page.

No spreadsheet migration is required.

## Direct API test
Open the deployed Apps Script URL with `?action=listSponsors`. The response should contain `"ok":true` and the saved sponsor records.
