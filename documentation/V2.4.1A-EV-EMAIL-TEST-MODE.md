# VISTA 2.4.1A — EV Email Test Mode

## Purpose

This hotfix allows administrators to temporarily test the complete EV charging request email and manager-approval workflow with accessible non-Ford email accounts.

The production-safe default remains Ford email addresses only.

## Configuration

Running `setupVista()` adds this Config key only when it does not already exist:

| Key | Default | Behavior |
| --- | --- | --- |
| `EV_REQUIRE_FORD_EMAILS` | `YES` | Employee and manager addresses must be `@ford.com` or a Ford subdomain. |

For a controlled test, change the value to:

```text
NO
```

With `NO`, VISTA accepts any syntactically valid employee and manager email addresses. Manager resolution still follows the existing order:

1. Active matching record in `Users`
2. Active matching record in `Sponsors`
3. Manager information entered on the request form

If a matching active `Users` record is found, its directory email must still match the submitted manager email. To test with an external address, use a manager CDSID that does not match an active VISTA user, or temporarily use an appropriate test record in `Sponsors`.

## Deployment

1. Replace the Apps Script project's `Code.gs` with `apps-script/Code.gs`.
2. Save the project.
3. Run `setupVista()` once.
4. In the `Config` worksheet, set `EV_REQUIRE_FORD_EMAILS` to `NO`.
5. Create a new version of the existing Apps Script web-app deployment.
6. Keep the current web-app URL and access settings.
7. Hard-refresh the EV Charging Access Request page with `Ctrl + F5`.
8. Confirm the footer shows `Version 2.4.1A`.

## Proof test

1. Use an employee email account you can inspect.
2. Use a different manager email account you can inspect.
3. Enter valid test CDSIDs and complete the request.
4. Confirm the employee receives the submission confirmation.
5. Confirm the manager receives the secure approval email.
6. Open the manager link and enter the exact manager CDSID recorded on the request.
7. Approve the request.
8. Confirm the employee receives the approval decision.
9. Repeat with a second request and test denial plus comments.
10. Verify `EVChargingRequests`, `EVChargingActivity`, and `AuditLog`.

## Restore production enforcement

After testing, set:

```text
EV_REQUIRE_FORD_EMAILS
YES
```

No code replacement or Apps Script redeployment is required when only this Config value changes. New submissions will immediately return to Ford-only email enforcement.
