# VISTA 2.1B Deployment and Test Guide

## Files changed
- `apps-script/Code.gs`
- `security-console/app.js`
- `security-console/index.html`
- `admin-console/index.html`
- `VERSION.json`
- `CHANGELOG.md`

## Deployment
1. Replace the deployed Apps Script project `Code.gs` with this build.
2. Save the script and deploy a **new web-app version** using the existing deployment settings.
3. Confirm the deployed URL remains the URL already stored in each console `config.js`.
4. Upload the repository files to GitHub and allow GitHub Pages to refresh.
5. Hard-refresh the Security and Administration consoles.

## Required role test
- **Security Supervisor**: can approve, deny, check in, check out, and mark no-show.
- **Security**: can view photos, check in/out, assign/return badges, and mark no-show; cannot approve or deny.
- **FrontDesk**: same operational workflow as Security, without approval authority.
- **Sponsor/Approver**: can only review visits assigned to their own email address.

## Regression test
1. Submit a new visitor registration with a captured photo.
2. Open it in Security Operations and confirm the image loads.
3. Approve it using a Security Supervisor account.
4. Confirm a Security account does not display Approve or Deny buttons.
5. Check the approved visitor in and assign a badge UID.
6. Check the visitor out with the same badge UID.
7. Confirm invalid repeated approval/check-in attempts are rejected with a clear message.
8. Test an older record containing `PhotoFileName` but no valid `PhotoFileId`; the photo should load when that named file exists in the configured folder.

## Apps Script redeployment
Required. The browser-only files will not activate the backend compatibility and RBAC changes until a new Apps Script web-app version is deployed.
