# VISTA 2.3.1A — Account Lock Recovery

## Immediate recovery for `sgrosse4`

After replacing `Code.gs`, select `recoverSgrosse4Account` from the Apps Script function dropdown and click **Run**. It executes:

```javascript
unlockVistaUserAccount('sgrosse4')
```

This clears `FailedLoginCount` and preserves the existing PIN.

If the PIN must also be changed, run:

```javascript
resetVistaUserPinAndUnlock('sgrosse4', 'NEW-PIN-HERE')
```

Use a private PIN value and do not store it in the repository or Config sheet.

## Deployment

1. Replace the Apps Script `Code.gs` with `apps-script/Code.gs` from this repository.
2. Save the project.
3. Run one of the recovery functions above.
4. Create a new web-app deployment version while retaining the existing URL.
5. Deploy the repository frontend through GitHub Pages.
6. Hard-refresh Administration with `Ctrl + F5`.

No spreadsheet migration or `setupVista()` run is required.

## Permanent Administration workflow

- Locked users display a Locked status and failed-attempt count.
- Select **Unlock** to clear the failed-attempt counter without changing the PIN.
- Select **Reset PIN** to assign a new PIN and clear the lock together.
- Successful badge authentication also clears accumulated PIN failures.
- Unlock and reset actions are written to the Audit Log.
