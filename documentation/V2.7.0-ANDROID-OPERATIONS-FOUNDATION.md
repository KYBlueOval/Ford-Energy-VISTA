# VISTA 2.7.0 — Android Operations Foundation

## Outcome

VISTA now includes an installable Android operations client with a native Ford Energy launcher and secure access to the complete web application suite.

The Android application does not create a second database or duplicate Apps Script configuration. It uses the deployed VISTA web applications and existing authenticated backend.

## Mobile capabilities

- NFC badge sign-in in Security Operations, Sponsor Portal, and Administration.
- NFC visitor badge capture during assignment, manual check-in, checkout, incident reporting, and credential management.
- Camera and photo-library access for visitor registration, manual visitor intake, incident/handoff evidence, and user profile photos.
- Wi-Fi and mobile-data operation with offline recovery.
- Native VISTA workspace launcher and module toolbar.
- Deep links for URLs under `https://kyblueoval.github.io/Ford-Energy-VISTA/`.
- Restricted WebView navigation and external handling for non-VISTA links.

## Installation test

1. Download the `Ford-Energy-VISTA-Android-2.7.0-debug` artifact from the GitHub Actions run.
2. On the Android test device, allow installation from the selected file source when prompted.
3. Install the APK and open Ford Energy VISTA.
4. Verify Wi-Fi/mobile data and NFC status at the top of the launcher.
5. Open Security Operations, authenticate, and perform the NFC/camera tests listed in `android-app/README.md`.

## Production hardening before managed rollout

- Create the Ford Energy production signing key and protected GitHub signing secrets.
- Produce a signed release App Bundle or APK.
- Confirm device-management distribution requirements.
- Complete physical NFC tests with every deployed employee and visitor badge technology.
- Complete camera, background-processing, and network tests on the intended managed Android hardware.
- Add an Android App Link verification file to the GitHub Pages domain if automatic link ownership is required.
