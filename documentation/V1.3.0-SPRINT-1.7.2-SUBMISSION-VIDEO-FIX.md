# VISTA v1.3.0 Sprint 1.7.2

## Fixes

- Registration uses a hidden form POST to Apps Script and polls the result through the existing JSONP-capable GET endpoint.
- Apps Script caches success or error results by request ID for ten minutes.
- The embedded Google Drive training player is restored. A new-tab fallback remains visible below it.
- The generated sponsor directory is intentionally excluded from this release package. GitHub Actions remains the sole owner of `public-registration/data/sponsors.json`.

## Deployment

1. Copy this package over the local GitHub Desktop repository.
2. Commit and push the frontend changes.
3. Replace Apps Script `Code.gs` and deploy a new version of the existing Web App deployment.
4. Do not run sponsor sync merely because of this deployment; the existing generated sponsor JSON is retained.
5. Test one registration and confirm the VisitRequests row, photo, acknowledgements, and emails.

## Duplicate protection

If a submission reaches the three-minute timeout, check the VisitRequests worksheet before clicking Submit again. The server may have completed the registration while the browser lost the acknowledgement.
