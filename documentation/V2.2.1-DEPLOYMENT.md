# VISTA 2.2.1 Deployment and Test Guide

## Scope
This sprint adds guided badge assignment/check-in, badge return/checkout, confirmation steps, and visitor/badge activity history.

## Deployment
1. Replace the Apps Script `Code.gs` with the file in this repository.
2. Save and deploy a new web-app version while retaining the existing web-app URL.
3. Upload the complete repository to GitHub Pages.
4. Wait for deployment, then hard-refresh Security Operations with `Ctrl + F5`.
5. Confirm the footer shows **Version 2.2.1**.

No spreadsheet schema changes or setup function are required. The existing `VisitActivity` sheet is used for the timeline.

## Test sequence
1. Open an Approved reservation and select **Assign Badge & Check In**.
2. Scan or enter a badge UID, review the summary, and confirm check-in.
3. Verify the reservation changes to **Checked In** and the badge appears in the record.
4. Review the Operational Timeline for the CHECK IN event.
5. Select **Return Badge & Check Out**, verify the same badge UID, and confirm checkout.
6. Verify the reservation changes to **Checked Out** and the timeline records checkout.
7. Attempt checkout with a different badge UID and confirm the backend blocks it.
8. Attempt to assign a badge already issued to another visitor and confirm the backend blocks it.
