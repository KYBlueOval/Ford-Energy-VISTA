# VISTA 2.6.2 — Visitor Responsibility & Advance Notice Standard

## Deployment

1. Push the complete repository to GitHub Pages.
2. Replace the Apps Script project `Code.gs` with `apps-script/Code.gs`.
3. Save the Apps Script project.
4. Run `setupVista()` once. If `VISITOR_ADVANCE_NOTICE_DAYS` is currently `7`, setup changes it to `14`. Any other customized value remains unchanged.
5. Create a new Apps Script web-app deployment version while preserving the existing URL.
6. Hard-refresh the Sponsor Portal and Administration with `Ctrl + F5`.

## Prove-out

1. Confirm the Config worksheet shows `VISITOR_ADVANCE_NOTICE_DAYS` = `14`.
2. Open a same-day or less-than-14-day visitor request and confirm it is flagged as late but remains eligible for submission and review.
3. Open a visitor at least 14 calendar days in advance and confirm the request meets the advance-notice standard.
4. In the Sponsor Portal, open a visitor and select **Assign Responsible Person**.
5. Confirm the responsibility notice states that the assigned person is responsible for day-to-day and operational supervision, receives arrival notifications, and performs day-of-visit coordination activities.
