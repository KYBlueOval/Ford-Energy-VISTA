# VISTA 2.3.0 — Badge Inventory Milestone 1

This milestone adds controlled visitor-badge inventory management while preserving the production Apps Script configuration, Drive folder IDs, public registration configuration, and Ford Energy branding.

## Deployment

1. Replace the Apps Script `Code.gs` with `apps-script/Code.gs` from this repository.
2. Save the Apps Script project and create a new web-app deployment version. Keep the existing web-app URL.
3. Upload the repository frontend to GitHub Pages.
4. Hard-refresh Administration with `Ctrl + F5`.

No spreadsheet migration or `setupVista()` run is required. The existing `BadgeInventory` sheet and columns are reused.

## Test sequence

1. Sign in to Administration as Admin or Super Administrator.
2. In Badge Inventory, add a badge number and scan or enter its UID.
3. Confirm duplicate badge numbers are rejected.
4. Mark a badge Lost, Broken, or Disabled.
5. In Security Operations, attempt to assign that badge during check-in and confirm issuance is blocked.
6. Return the badge to Available in Administration and complete check-in.
7. Confirm the inventory row changes to Issued and contains the current Visit ID.
8. Complete checkout and confirm the badge returns to Available with a returned timestamp.
9. Confirm badge create, edit, and status changes appear in the Administration audit feed.

Issued badges are intentionally locked in Administration. They must be returned through the Security Operations checkout workflow to preserve visit and audit integrity.
