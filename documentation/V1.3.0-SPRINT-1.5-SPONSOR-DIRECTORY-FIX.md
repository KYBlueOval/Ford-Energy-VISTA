# VISTA v1.3.0 Sprint 1.5 — Sponsor Directory Fix

The public registration page now loads sponsor records from the same GitHub Pages origin:

`public-registration/data/sponsors.json`

This removes Google Apps Script CORS, JSONP, redirect, and iframe-bridge failures from sponsor lookup.

## Updating sponsors

Edit `public-registration/data/sponsors.json`, preserve valid JSON, and commit it to GitHub. Each sponsor record uses:

- `sponsorId`
- `name`
- `email`
- `department`
- `keywords`

The Google Sheet remains the operational sponsor source, but the public lookup directory is a GitHub-hosted mirror to guarantee browser compatibility.
