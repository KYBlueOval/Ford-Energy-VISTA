# VISTA 2.4.4 — Focused Security Operations Dashboard

## What changed

Security Operations now presents the workflows officers use most often in a clear order:

1. Live operational KPIs
2. Full-width Alerts & Notifications
3. Visitor Records and the selected Visitor Record workspace
4. Launchers for supporting operational tools

The supporting tools are Live Site Accountability, Security Reporting, and Shift Accountability. Selecting a launcher opens only that workspace. Close Workspace or Back to Operational Tools returns to the compact dashboard.

Launcher summaries remain current when Security data refreshes. Direct links are supported with:

- `#security-accountability`
- `#security-incidents`
- `#security-handoffs`

All existing operational permissions and workflows are preserved.

## Deployment

This is a frontend-only milestone.

1. Publish the repository contents to GitHub Pages.
2. Wait for the Pages deployment to complete.
3. Hard-refresh Security Operations with `Ctrl + F5`.

No Apps Script deployment, `setupVista()` run, Config change, or spreadsheet migration is required.

## Proof test

1. Sign in to Security Operations.
2. Confirm Expected Today, Currently Onsite, Checked Out Today, and Overdue remain at the top.
3. Confirm Alerts & Notifications spans the full content width.
4. Search for and open a visitor. Verify approval, check-in, badge, photo, and checkout controls behave as before.
5. Select each Operational Tools launcher. Verify only the chosen supporting workspace opens.
6. Use Close Workspace and each Back to Operational Tools control.
7. Verify an alert acknowledgement still records normally.
8. Verify Incident Reporting and Officer Handoff actions still save and refresh.
9. Repeat the layout check on a phone or narrow browser window.
