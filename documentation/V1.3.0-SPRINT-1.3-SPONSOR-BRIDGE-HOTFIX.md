# VISTA v1.3.0 Sprint 1.3 — Sponsor Bridge Hotfix

The public GitHub Pages registration site can read the sponsor directory through a hidden Apps Script HTML bridge using `window.postMessage`. This avoids the Google Apps Script ContentService redirect/CORS failure observed with direct `fetch` and JSONP requests.

## Deployment
1. Replace Apps Script `Code.gs`.
2. Deploy a new Web App version.
3. Upload the complete GitHub project.
4. Hard-refresh the registration page.

## Test
Open the registration page with `?v=13013`, proceed to Step 2, and search for a sponsor. The browser console should show `VISTA sponsor directory loaded: 1`.
