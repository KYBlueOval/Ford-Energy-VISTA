# Ford Energy VISTA v1.3.0 Sprint 1.7

## Included
- Sponsor sync freshness and active sponsor count on the registration form.
- Same-origin sponsor refresh button and cached fallback.
- Improved multi-token sponsor search ranking.
- Automatic local draft saving and clear restored-draft notice.
- Google Drive training video launch card to avoid iframe CSP failures.
- Verified GitHub Actions sponsor sync workflow using the production Apps Script deployment.

## Deployment
1. Copy the package contents over the local GitHub Desktop repository.
2. Review changes in GitHub Desktop.
3. Commit with `Deploy VISTA Sprint 1.7`.
4. Push origin.
5. Run `Sync VISTA Sponsors` once under GitHub Actions.
6. Hard refresh the registration page.

## Sponsor administration
Continue editing only the Google Sheets `Sponsors` tab. Active rows are synchronized every five minutes. The registration page now displays the active count and last generated time from `sponsors.json`.
