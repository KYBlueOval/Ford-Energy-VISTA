# VISTA v1.3.0 Sprint 1.2

This hotfix resolves the case where the Apps Script `listSponsors` URL returns valid JSON in a browser tab but GitHub Pages cannot read it because of cross-origin restrictions after the Apps Script redirect.

The public registration page now loads the sponsor directory through JSONP. The Apps Script `doGet` handler supports a sanitized `callback` parameter and returns JavaScript when present.

## Deployment
1. Replace the Apps Script `Code.gs`.
2. Deploy a new web-app version.
3. Upload the GitHub package over the repository.
4. Hard-refresh the registration page.

## Verification
Open the registration page and type `Justin`, `Security`, `Ysunza`, or `jysunza@ford.com`. The saved sponsor should appear and populate name, email, department, and SponsorID.
