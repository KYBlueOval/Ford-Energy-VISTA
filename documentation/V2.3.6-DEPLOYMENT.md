# VISTA 2.3.6 — Reporting and Export

## Deployment

1. Replace the Apps Script `Code.gs` with `apps-script/Code.gs` from this release.
2. Save the Apps Script project.
3. Create a new web-app deployment version and retain the existing web-app URL.
4. Deploy the repository contents to GitHub Pages.
5. Hard-refresh Administration with `Ctrl + F5`.

No spreadsheet migration or `setupVista()` run is required. Existing Config values, roster sheets, Drive folder IDs, sponsors, visitors, badges, handoffs, and audit records remain unchanged.

## Report types

- Operational Summary
- Visitor Activity
- Badge Inventory
- Shift Handoffs
- Audit Log

## Test sequence

1. Sign in to Administration as Admin or Super Administrator.
2. Locate `Reports & Export` beneath VISTA Analytics.
3. Generate each report type for the default 30-day period.
4. Test the 7-day, 90-day, and 12-month periods.
5. Enter an optional filter and confirm only matching rows appear.
6. Export each report to CSV and open it in Excel or Google Sheets.
7. Confirm headings, UTF-8 text, dates, badge UIDs, and row values remain correctly separated.
8. Select Print Report and confirm the print preview contains only the Ford Energy report header, report table, and report footer.
9. Verify a report exceeding 1,000 matching records displays the truncation notice.
10. Confirm `AuditLog` records `REPORT_GENERATED` and `REPORT_EXPORTED`.
11. Confirm an unauthorized session cannot call either reporting endpoint.

## Security notes

- Report data remains behind authenticated Apps Script endpoints.
- CSV fields beginning with spreadsheet formula characters are neutralized before download.
- Reports are generated on demand and are not uploaded to another service.
- Exported files are downloaded only to the administrator's local device.
