# VISTA v1.2.2 Sponsor Directory

## Purpose
The public registration form now provides a searchable Sponsor Email field while retaining manual entry for sponsors not listed in the directory. Selecting a stored email automatically fills the sponsor name and department.

## Setup
1. Replace Apps Script `Code.gs` with the v1.2.2 file.
2. Run `setupVisitorManagement()`. This creates the `Sponsors` sheet.
3. Add approved directory entries using these columns:
   - SponsorID
   - SponsorName
   - SponsorEmail
   - Department
   - Active (`Yes` or `No`)
   - SearchKeywords (optional aliases, project names, or abbreviations)
   - LastUpdatedAt
4. Deploy a new Apps Script Web App version.
5. Upload the GitHub files and hard refresh the registration page.

## Manual Entry
The Sponsor Email control remains an email input. Visitors can type an unlisted valid email. Sponsor Name and Department remain required and can be entered manually.

## Directory Scope
Only add employees approved to sponsor visitors. The directory is returned to the public registration application, so do not place confidential roster data in this sheet.
