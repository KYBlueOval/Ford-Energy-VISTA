# VISTA 2.1C — Identity Profile Photos

## Included
- Badge-photo upload in Add User and Edit User.
- Browser-side resizing before upload.
- Image saved to the shared Drive folder configured by `USER_PHOTO_FOLDER_ID`; falls back to `PHOTO_FOLDER_ID`.
- Drive file ID, filename, and URL saved in the Users sheet.
- Circular signed-in profile photo in Administration and Security Operations headers.

## Deployment
1. Replace Apps Script `Code.gs` and save.
2. Run `setupVista()` once so the three new Users columns and config key are added.
3. In the Config sheet, set `USER_PHOTO_FOLDER_ID` to the shared Google Drive folder ID. If blank, VISTA uses `PHOTO_FOLDER_ID`; if both are blank it uses the Apps Script owner's My Drive root.
4. Deploy a new Apps Script web-app version without changing the web-app URL.
5. Publish the GitHub Pages files and hard refresh with Ctrl+F5.

## Test
- Edit an existing user, upload a JPG/PNG, save, sign out, then sign back in as that user.
- Confirm the image is in Drive and `UserPhotoFileId`, `UserPhotoFileName`, and `UserPhotoUrl` are populated in Users.
- Confirm the circular photo appears in both Administration and Security Operations.
