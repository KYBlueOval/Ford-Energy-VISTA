# VISTA 2.3.2 — Active Visitor Accountability

## Deployment

1. Replace the Apps Script `Code.gs` with `apps-script/Code.gs` from this repository.
2. Save the Apps Script project and create a new web-app deployment version while retaining the existing URL.
3. Deploy the repository frontend through GitHub Pages.
4. Hard-refresh Security Operations with `Ctrl + F5`.

No spreadsheet migration or `setupVista()` run is required. Production configuration and Drive folder IDs remain unchanged.

## Test sequence

1. Check in at least two approved visitors with numbered badges.
2. Confirm both appear under **Active Visitors & Badges Out**.
3. Verify each card shows visitor, company, sponsor, onsite duration, badge number, expected departure, and escort requirement.
4. Confirm the Visitors Onsite and Badges Out counts reflect current records.
5. Use **Open / Check Out** and complete checkout. Confirm the visitor disappears from the live view after refresh.
6. Use a visit with a past planned departure and confirm it displays Overdue.
7. Check out a badge as Broken or Lost and confirm it appears in the Badge Exception Queue.
8. Confirm Lost/Broken counts match Administration Badge Inventory.
9. Verify the existing visitor search, approvals, photographs, timeline, check-in, and checkout workflows still operate.
