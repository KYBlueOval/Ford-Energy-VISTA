# VISTA v1.3.0 Sprint 1 — Sponsor Picker

## Deployment
1. Replace the GitHub repository files with this package.
2. Replace Apps Script `Code.gs`.
3. Run `setupVisitorManagement()` once. This adds `SponsorID` and `SponsorSource` without deleting existing rows.
4. Deploy a new Apps Script web-app version.
5. Hard refresh the registration page.
