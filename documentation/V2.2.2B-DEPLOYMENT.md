# VISTA 2.2.2B Deployment and Test Guide

## Scope

This frontend-only increment adds a high-visibility translucent Ford blue gradient footer to Visitor Registration, Security Operations, and Administration. It also replaces the BWRDO asset with a tightly cropped transparent version so the logo is clearly visible.

## Deployment

1. Upload the complete repository contents to GitHub.
2. Wait for GitHub Pages to finish deploying.
3. Hard-refresh each module with `Ctrl + F5`.
4. No Apps Script update, sheet migration, or `setupVista()` run is required.

## Test pages

- `/public-registration/`
- `/security-console/`
- `/admin-console/`

Confirm that each page shows:

- A full-width translucent Ford blue gradient footer.
- A clearly visible centered BWRDO logo.
- White/light-blue module and version text.
- `Version 2.2.2B`.
- Responsive footer layout at narrow browser widths.

## Regression checks

- Visitor registration navigation and draft functions still work.
- Security badge and PIN login still work.
- Administration badge and PIN login still work.
- Existing 2.2.2A modal, photo, badge, and operational workflows are unchanged.
