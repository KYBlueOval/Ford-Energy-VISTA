# VISTA 2.5.5A — Sponsor Metric Serialization Hotfix

## Corrected behavior

- Advance-notice values stored in date-formatted Google Sheets cells are converted back to their intended numeric day/hour values.
- Same-day requests display a practical non-negative lead time instead of epoch milliseconds.
- Sponsor and Security approval dialogs use the updated parking and office/seating examples.
- Running setup applies numeric formats to the advance-notice and approval-response columns so future values remain numeric.

## Deployment

1. Replace the Apps Script project `Code.gs` with `apps-script/Code.gs` from this build.
2. Save the Apps Script project.
3. Run `setupVista()` once. This preserves existing records and corrects the affected column formats.
4. Create a new web-app deployment version while retaining the existing deployed URL.
5. Deploy the repository files to GitHub Pages.
6. Hard-refresh the Sponsor Portal and Security Operations pages with `Ctrl + F5`.

## Verification

1. Open a same-day submitted request in the Sponsor Portal.
2. Select **Approve Request**.
3. Confirm the notice shows a small non-negative day value and the configured required days.
4. Confirm the parking example lists the Ford Energy Blue and Contractor Orange lots.
5. Confirm the office/seating example reads `Electrode · Room K-134 · 134.27`.
6. Repeat the approval-dialog check in Security Operations.

Existing visitor requests do not need to be deleted or recreated.
