# VISTA 2.4.3 — Focused Administration Dashboard

## Purpose

Administration is now organized as a dashboard instead of a continuous vertical collection of unrelated panels.

VISTA Analytics remains visible directly below the Administration header. The remaining management areas are opened from a consistent launcher grid:

- Security Operations Communication
- Reports & Exports
- VISTA Active Directory
- Badge Inventory
- EV Charging Access Control
- VISTA Activity Logs

Only one management workspace is displayed at a time.

## Navigation behavior

Select a launcher tile to open that workspace below the dashboard. The selected tile uses the Ford blue active treatment.

Select another tile to switch workspaces. Select **Close Workspace** to return to the Analytics and launcher-only dashboard.

The selected workspace is also reflected in the page address:

```text
#admin-communications
#admin-reports
#admin-directory
#admin-badges
#admin-ev
#admin-activity
```

These addresses can be bookmarked after signing in. Existing authentication and role restrictions continue to apply.

## Live launcher summaries

The launcher tiles display current summary information after Administration loads:

- VISTA Active Directory: total users
- Badge Inventory: total visitor badges
- EV Charging Access Control: pending request count
- Security Operations Communication: active alert count

## Preserved functionality

This release does not change:

- Administration permissions
- User creation, editing, account unlocking, PIN reset, or profile photographs
- Alert publishing or acknowledgement tracking
- Reports and exports
- Badge inventory actions
- EV request decisions or Facilities notifications
- Audit logging
- Apps Script configuration
- Ford Energy branding

The **+ Add User** action opens the VISTA Active Directory workspace before displaying the user dialog.

## Deployment

VISTA 2.4.3 is a frontend-only release.

1. Publish the updated repository to GitHub Pages.
2. Wait for the Pages deployment to complete.
3. Hard-refresh Administration with `Ctrl + F5`.
4. Confirm the footer displays `Version 2.4.3`.

No `Code.gs` replacement, Apps Script deployment, `setupVista()` run, or spreadsheet migration is required if v2.4.2 is already deployed.

## Proof test

1. Sign in to Administration as an Admin or Super Administrator.
2. Confirm VISTA Analytics is the first panel below the Administration header.
3. Confirm the six launcher tiles appear below Analytics.
4. Confirm no management workspace is open initially.
5. Open each launcher and verify only that workspace is displayed.
6. Switch directly between two launchers and confirm the first workspace closes.
7. Select **Close Workspace** and confirm all workspaces close.
8. Select **+ Add User** and confirm the Active Directory workspace becomes active before the Add User dialog opens.
9. Test one existing action in every workspace.
10. Verify the layout on a phone or tablet and confirm there is no horizontal page scrolling.
