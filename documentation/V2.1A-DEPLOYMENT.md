# VISTA Sprint 2.1A Deployment

1. Upload the repository files to GitHub Pages.
2. Replace Apps Script `Code.gs` with `apps-script/Code.gs`.
3. Deploy a **new Apps Script web app version**, executing as you, with access set to Anyone.
4. Confirm `admin-console/config.js` contains the active `/exec` deployment URL.
5. Sign in at `/admin-console/` with an existing Admin account.
6. Add another Super Administrator through **Add User**. New users require a PIN.

The existing `Users` and `AuditLog` sheets are used; no new sheet is required.
