# VISTA v1.2.1 Photo Filename Hotfix

New visitor photographs use the visitor full legal name and company/business party:

- `John Alan Doe-Clarion.jpg`
- `Jane Elizabeth Smith-Walbridge.png`

The Security Console includes a **Download Photo** button so the local download retains the same name for uBioAlpeta facial-recognition enrollment.

## Deploy
1. Replace Apps Script `Code.gs`.
2. Run `setupVisitorManagement()` once to add the optional `PhotoFileName` column.
3. Deploy a new Apps Script web-app version.
4. Upload the GitHub files.
5. Hard refresh the Security Console.

Existing photos are not renamed automatically. New registrations use the new naming rule.
