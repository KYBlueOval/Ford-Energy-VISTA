# VISTA 2.3.1 — Security Badge Control

This milestone connects Security Operations directly to the Badge Inventory introduced in 2.3.0. It preserves production Apps Script configuration, Drive folder IDs, public registration configuration, and Ford Energy branding.

## Deployment

1. Replace the Apps Script `Code.gs` with `apps-script/Code.gs` from this repository.
2. Save the Apps Script project and create a new web-app deployment version. Keep the existing web-app URL.
3. Deploy the repository frontend through GitHub Pages.
4. Hard-refresh Security Operations and Administration with `Ctrl + F5`.

No spreadsheet migration or `setupVista()` run is required.

## Test sequence

1. In Administration, confirm at least two visitor badges are Available and have badge numbers.
2. Sign in to Security Operations as a regular Security user and open an Approved visitor.
3. Open **Assign Badge & Check In** and confirm the available-badge list shows numbered credentials.
4. Select a badge and confirm its UID fills automatically and displays an Available indicator.
5. Scan or enter a Lost, Broken, Disabled, or Issued UID and confirm check-in is blocked.
6. Enter an unknown UID and confirm a regular Security or Front Desk account cannot register it.
7. Sign in as Security Supervisor or Admin, enter an unknown UID, enable the supervised registration override, assign a unique badge number, and complete check-in.
8. Confirm the new badge appears in Administration and an audit event records its supervised registration.
9. Check out a visitor with condition **Available** and confirm the badge returns to the available list.
10. Repeat checkout with condition **Broken** or **Lost** and confirm that badge remains unavailable in Administration.
11. Review the visitor timeline and Administration audit feed for badge number, assignment, return, and condition details.

## Permission behavior

- Admin and Super Administrator: manage inventory and register unknown UIDs during check-in.
- Security Supervisor: register unknown UIDs during supervised check-in but cannot manage the Administration inventory.
- Security and FrontDesk: select or scan registered Available badges only.
- Sponsor, Approver, Reporting, and Read Only: no badge issuance privileges.
