# VISTA 2.3.8 — Administration Alert Broadcasts

## Included

- Administration alert composer with title, priority, effective timestamp, optional expiration, detailed information, and optional image.
- Active alerts remain visible on the Security Operations dashboard after acknowledgement.
- Each signed-in Security Operations user receives an acknowledgement-required login dialog until they sign off.
- Acknowledgements are recorded individually with user ID, username, full name, role, date, time, and user agent.
- Administration can review acknowledgement totals, view the protected image, and archive a broadcast.
- Every publish, acknowledgement, and archive action is written to `AuditLog`.

## Deployment

1. Replace the Apps Script `Code.gs` with `apps-script/Code.gs`.
2. Save the project and run `setupVista()` once.
   - Existing `Notifications` data is preserved.
   - Additional notification columns are appended.
   - The new `NotificationAcknowledgements` sheet is created.
   - Existing Config values are not replaced.
3. Keep `INCIDENT_PHOTO_FOLDER_ID` set to the approved shared folder. Alert images use this folder and receive unique file names.
4. Create a new Apps Script web-app deployment version while retaining the existing URL.
5. Publish the repository to GitHub Pages.
6. Hard-refresh Administration and Security Operations.

## Proof test

1. Sign in to Administration.
2. Locate **Alert & Notification Broadcasts**.
3. Enter a title, priority, effective date/time, information, and optional image.
4. Publish the alert and confirm it appears under Published alerts.
5. Sign out, then sign in to Security Operations as a Security user.
6. Confirm the alert opens automatically and cannot be dismissed without acknowledgement.
7. Select **Acknowledge Alert**.
8. Confirm the alert remains visible in the dashboard panel and displays **Acknowledged by you**.
9. Sign in as a second Security user and verify that user receives an independent acknowledgement prompt.
10. Return to Administration and confirm the acknowledgement count increased.
11. Verify `NotificationAcknowledgements` contains separate rows for each user.
12. Verify `AuditLog` contains `ADMIN_ALERT_PUBLISHED`, `NOTIFICATION_ACKNOWLEDGED`, and—after archiving—`ADMIN_ALERT_ARCHIVED`.
