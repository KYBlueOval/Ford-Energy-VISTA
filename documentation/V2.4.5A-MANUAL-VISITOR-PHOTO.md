# VISTA Version 2.4.5A — Processed Manual Visitor Portraits

## Included

- Take Photo and Retake Photo controls in Manual Visitor Check-In.
- Upload Photo fallback for desktop, tablet, and mobile devices.
- Automatic center crop to a 900 × 1200 (3:4) visitor portrait.
- Automatic visitor background removal using the same MediaPipe processing used by public registration.
- Standard VISTA light-blue (`#d8eaf8`) replacement background.
- Live processed-photo preview with Remove and Prepare ID Photo retry controls.
- Safe camera shutdown when the intake closes, is cancelled, or advances to authorization.

## Deployment

This is a frontend-only update. No Apps Script replacement, new deployment, spreadsheet migration, or Config change is required.

1. Allow GitHub Pages to finish deploying the updated repository.
2. Hard-refresh Security Operations with `Ctrl + F5`.
3. Sign in with a Front Desk or elevated Security Operations account.
4. Open **Manual Visitor Check-In**.

## Proof-out

1. Select **Take Photo** and grant camera permission.
2. Center the visitor in the preview and select **Capture & Process**.
3. Confirm the preview is a 3:4 portrait with a light-blue background.
4. Select **Retake Photo** and confirm the previous camera stream was stopped before the new one opens.
5. Test **Upload Photo** and confirm uploaded images receive the same crop and background processing.
6. Select **Prepare ID Photo** to retry background processing.
7. Complete the manual visitor authorization and check-in.
8. Open the visitor record and confirm the protected photograph displays normally.

If the browser cannot load the background-removal model, VISTA retains the cropped portrait and allows the officer to retry without losing the image.
